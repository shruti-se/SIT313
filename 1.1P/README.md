# DEV@Deakin – Personal Website

## Project Overview
This project is a personal website created for 'SIT313 – Secure Frontend Applications'. The website is part of the DEV@Deakin platform and demonstrates the use of HTML and CSS to create a simple, responsive personal portfolio webpage.

## Features
* Horizontal navigation menu with 'About, Work, and Contact'
* Full-screen banner image
* Hover effect on the banner displaying a personal message
* Personal introduction section
* Display of previously completed projects
* Project images with hover effects
* Responsive image gallery
* Images automatically rearrange according to the screen size

## Technologies Used
* HTML– Used to structure the webpage and its content.
* CSS – Used for styling, layout, hover effects, and responsive gallery design.

The HTML page is connected to an external 'style.css' stylesheet.

## Main Sections:

### Navigation
The website contains navigation options for About, Work, and Contact.

### Banner
A large banner image is displayed at the top of the webpage. When the user hovers over the banner, a message appears at the bottom of the image.

### Projects
The project section displays three project images representing previously completed work.

### Image Gallery
The website includes a gallery containing multiple images. CSS columns are used so that the gallery can rearrange itself based on the available screen width.

## Purpose
The main purpose of this project is to practise foundational frontend development skills, particularly HTML structure, CSS styling, layouts, hover effects, and responsive design.
